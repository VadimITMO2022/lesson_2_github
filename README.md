# Учебный проект по созданию файла main.py на языке Python и загрузки его на GitHub

# Как запустить

1. Склонируйте репозиторий или скачайте файл с кодом на свой компьютер

2. Запустите скрипт в терминале командой python main.py

# У скрипта в файле main.py две версии

номер версии \ название версии(коммита) \ что делает

1 \ "First commit" \ выводит текстовое сообщение

2 \ "added loop in main.py" \ тестирует цикл на языке Python

#  Что было сложным

1. настроить Git на домашнем компьютере

2. связать репозиторий Git на домашнем компьютере и соответствующий репозиторий на GitHub
